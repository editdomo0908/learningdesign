USING THIS PORTFOLIO

Accessibility.

This portfolio is being improved toward WCAG 2.2 Level AA. This page describes the support available and the gaps that remain.

Using the site

  • Use Tab and Shift + Tab to move between links and controls. Activate buttons with Enter or Space, and links with Enter.
  • The first keyboard link skips the header and moves to the main content.
  • On smaller screens, the menu button opens navigation. Escape closes it and returns focus to the menu button.
  • In the learning goal matcher, use Up and Down arrows, Home and End to choose a desktop tab. On smaller screens, use the labelled dropdown. The selected methods appear below.
  • The theme control switches between light and dark colours. Reduced-motion preferences from your device are respected.

Media and known limitations

Silent portfolio walkthroughs have expandable text descriptions. The instructional-video excerpt contains audio and does not yet have a supplied caption track or a full transcript. Its short written overview is not a replacement for captions.

The Storyline player has not had a full accessibility review. The separately hosted feedback course and third-party websites are outside this portfolio review.

Review scope

Work on this site uses the WCAG 2.2 accessibility guidelines as a reference. Automated checks and keyboard checks support the review, but do not replace evaluation with screen readers and disabled users. Full conformance has not been established.

Last reviewed: 21 October 2026.

Report an accessibility problem

Email edit.domoszlai@gmail.com with the page and the action that caused difficulty. If a video is inaccessible, you can request an alternative format.
