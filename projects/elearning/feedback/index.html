02 / INTERACTIVE LEARNING / WEB SIMULATION

The feedback conversation.

A simulated workplace conversation for practising specific, useful feedback.

Portfolio project · Ready to try

PROJECTFictional workplace scenario · Interactive web course
FORMATBrowser-based simulation · Ready to try
01 / PROBLEM

Turn a difficult moment into a conversation

The scenario starts with a late project handover and a draft message that blames a teammate. The task is to turn that draft into a clear, useful conversation.

02 / RESPONSE

Practise the words and the next step

Learners revise the draft, choose from three conversation approaches and make a follow-up decision. Each route shows a different response, followed by a short knowledge check.

03 / RESULT

A browser-based learning experience

The course lets learners explore different routes and review feedback on their decisions. It recreates a slide-based course experience using HTML, CSS and JavaScript.

An independent portfolio simulation with fictional people and conversations. Built for the web.
